# Extension Icons

Place icon files here:
- `icon16.png` - 16x16 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Design Guidelines

- Use MarginGap brand colors
- Simple, recognizable symbol (e.g., price tag, chart, or "MG" monogram)
- High contrast for visibility
- Works at small sizes (16px)

## Temporary Icons

Until final icons are designed, you can:
1. Use a placeholder image
2. Generate simple colored squares
3. Use a text-based icon generator
